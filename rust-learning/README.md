# rust-learning

Plantilla mínima para empezar a aprender Rust.

## Requisitos

- [Rustup](https://rustup.rs/)

## Primeros pasos

```bash
cd rust-learning
cargo run
```

## Próximos ejercicios sugeridos

1. Variables, mutabilidad y tipos.
2. Control de flujo (`if`, `match`, `loop`, `while`, `for`).
3. Propiedad y préstamos (ownership/borrowing).
4. `struct`, `enum` y `impl`.
5. Manejo de errores con `Result` y `Option`.
6. Módulos y `crates`.
7. Tests con `cargo test`.
